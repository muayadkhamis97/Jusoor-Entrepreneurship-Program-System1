---
name: Jusoor analytics tracking
description: Scope decisions for attendance and impact reporting in the entrepreneurship program.
---

Coordinators need a session attendance register and customizable impact KPIs for program monitoring.

**Why:** The coordinator selected attendance tracking and customizable KPIs; treating unrecorded outcomes as zero would misstate program results.

**How to apply:** Keep analytics coordinator-only and preserve the difference between missing records and measured zero values.

For poll and survey participation rates, use the distinct businesses on accepted applications in the program as the eligible cohort. A draft activity has no response rate because participants could not respond yet.

**Why:** Only accepted businesses are eligible to participate, and counting drafts as zero engagement would misstate session participation.

**How to apply:** Keep participation aggregates coordinator-only, count responses without selecting answer payloads, and show a rate as unavailable when no denominator exists or an activity is still a draft.

Saved report layouts are shared with coordinators in one program and store only the report title and section choices, never analytics results.

**Why:** Coordinators should reuse a common program report structure while each run reflects current database data and continues to distinguish unrecorded values from zero.

**How to apply:** Scope layout reads and changes to the selected program, and build every print or export from the current analytics queries.
