Use the built-in Jusoor platform LRS for learning records produced by SCORM/Tin Can course packages. Do not require an external LRS connection unless the user changes this decision.

**Why:** The user chose an LRS built into Jusoor.

**How to apply:** Keep package xAPI records and activity state within the platform's existing API and database.
