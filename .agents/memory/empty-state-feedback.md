---
name: Empty-state feedback
description: Product expectation for empty lists and report panels.
---

Show a clear, contextual message when a list or panel has no records instead of leaving it blank.

**Why:** The user requested messages explaining when sections are empty, using the mentor meeting reports page as an example.

**How to apply:** Distinguish no assigned programs, no records yet, and no matches for active filters. Explain the relevant next step. Keep failed requests separate from successful empty responses, and do not show zero counts as if failed or unloaded data were known to be empty.
