name: Footer branding
description: Keep page-end labels generic instead of repeating a hard-coded organization name.
---

Do not include a hard-coded organization name in page-end footers. Keep operational and report footer labels generic; retain configured branding in the surfaces designed to display it.

**Why:** The user asked to remove the static organization label from page ends and has configured dynamic branding elsewhere.

**How to apply:** When adding or editing footers, avoid organization-name copy. Do not remove dynamic branding from headers or other branding surfaces.
