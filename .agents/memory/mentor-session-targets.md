---
name: Mentor session targets
description: Program-level 1:1 session targets, report counts, and extra-session requests
---

Each program sets one planned 1:1 session count per business. Submitted mentor meeting reports count toward that target. Reaching it does not block further reports; it enables a mentor to request additional sessions. Staff-approved additions raise only that business's effective target, not the program default. Requests must be scoped to the mentor's assigned business and program, recorded for staff review, and sent to the active admin and assigned program staff. Failed alerts can be retried without duplicating successful deliveries.

**Why:** the user chose one default per program and approved per-business decisions and retries for extra-session requests.

**How to apply:** count submitted reports by business, show progress against its effective target, and preserve mentor/staff assignment boundaries and idempotent email delivery.
