---
name: Mentor session targets
description: Program-level 1:1 session targets, report counts, and extra-session requests
---

Each program sets one planned 1:1 session count per business. Submitted mentor meeting reports count toward that target. Reaching it does not block further reports; it enables a mentor to request additional sessions. Requests must be scoped to the mentor's assigned business and program, recorded for staff review, and sent to the active admin and assigned program staff.

**Why:** the user chose one default per program and wants mentors to notify the project team when they need more sessions.

**How to apply:** count submitted reports by business, show progress against the program target, and preserve mentor and staff program-access boundaries when handling requests.
