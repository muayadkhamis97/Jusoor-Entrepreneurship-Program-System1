Work only on the current **Jusoor Entrepreneurship Program System** project.

## Objective
Verify that `20261014_program_assignments_and_archival.sql` applies correctly to a genuinely disposable PostgreSQL database and that program assignment, archival, restoration, and data-retention behavior work as intended.

- Confirm the database connection cannot target the application's existing development database or production.

## 2. Migration verification
Against the isolated disposable database only:

- Program archival preserves applications, businesses, courses, participants, evaluations, and audit history.
- Restoration makes an archived program available again without duplicating records.

- Unauthorized cross-program access remains denied.

- Confirm that cleanup targets only resources created by this test run.
- Stop the disposable database before removing its temporary data directory.
- If shutdown fails, stop cleanup and preserve the directory for investigation.
